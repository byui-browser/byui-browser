About this browser

Every part of BYUI Browser — the HTML parser, CSS engine, layout, painting, networking, and JavaScript engine — is written by students in Rust, without borrowing an existing browser engine.

This page is drawn by that engine. If the oak, the tiles, or the shortcuts look wrong, something in the engine just broke.

Found a bug? Open an issue on our GitHub repository.
