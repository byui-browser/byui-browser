# Git Help

## Common Git Commands

`git status` - view any ustaged or un committed changes to the current branch from the remote
`git add .` - We are going to let Git know that it needs to track all untracked files
`git add FILE_OR_FOLDER_NAME` - Let Git know to track a specific file or files
`git commit -m 'message'` - This takes all tracked files and adds them into a package ready to be pushed to Github
`git push` - This syncs the repository with Github
