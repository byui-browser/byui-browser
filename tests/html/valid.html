Parser notes

Building a Small HTML Tree

Written by Ada Lovelace

Overview

HTML documents are trees made from elements, attributes, and text.

A useful parser keeps relationships explicit and predictable.

Core concepts

  1. Elements have names and attributes.
  2. Children preserve document order.
  3. Text belongs to the element that contains it.

Example

<article>Hello</article>

This example is intentionally small.

Node summary

Common node properties
PropertyPurpose
NameIdentifies an element type.
AttributesStores element metadata.
ChildrenConnects nested elements.

Remember

Malformed input should not make a tree builder panic.

Checklist

  • Read the input.
  • Create stable node identifiers.
  • Attach children to parents.
  • Keep attributes available.
  • Collect text content.

Details

Why use an arena?

Arena identifiers make references small and stable.

  • Stable handles simplify references.
  • Explicit parents simplify traversal.

Traversal stays deterministic.

The fixture ends with a complete document tree.
